## Призначення системи

«PersonalProjectNotes» - це вебсистема для ведення персональних проєктних нотаток і керування задачами. Основне призначення системи полягає в наданні користувачу зручного середовища для створення дошок, списків і карток задач, їх редагування, архівування, пошуку, коментування та перегляду історії активності.

Система реалізується у вигляді клієнт-серверного застосунку. Серверна частина надає REST API для роботи з обліковими записами, дошками, списками, картками, коментарями, активністю користувачів та інтеграцією з AI-сервісом. Доступ до захищених функцій здійснюється після автентифікації користувача з використанням JWT-токенів.

За логікою роботи система наближена до Kanban-підходу: користувач створює дошку для проєкту, додає до неї списки, а в списках розміщує картки з описом задач, строками виконання, статусом і пріоритетом. Для командної роботи передбачено додавання співучасників до дошки, перегляд списку учасників та керування доступом.

## Цілі створення системи

Метою створення системи є автоматизація процесу ведення особистих і проєктних нотаток, а також підвищення зручності керування задачами. Система має забезпечити користувачу можливість швидко створювати задачі, групувати їх за дошками та списками, контролювати статус виконання, пріоритет і строки.

Додатковою ціллю є підтримка спільної роботи. Користувач має мати можливість надати доступ до окремої дошки іншим користувачам, щоб вони могли переглядати й брати участь у роботі над задачами відповідно до передбаченої бізнес-логіки.

Також система має забезпечити прозорість змін через фіксацію активності на рівні дошок, списків і карток. Це дає змогу відстежувати основні дії користувачів та аналізувати хід роботи над проєктом.

Окремим напрямом розвитку є інтеграція з AI-сервісом Gemini, що дозволяє надсилати текстові запити до моделі та отримувати відповіді в межах функціональності системи.

## Загальні принципи побудови та функціонування системи

Система «PersonalProjectNotes» побудована за багаторівневою архітектурою з розділенням відповідальності між окремими проєктами:

- **PersonalProjectNotes** - веб API, контролери, конфігурація застосунку, Swagger, CORS, автентифікація та запуск системи;
- **PersonalProjectNotes.Domain** - доменні сутності, запити, відповіді та перелічення;
- **PersonalProjectNotes.Data** - контекст бази даних Entity Framework Core та міграції;
- **PersonalProjectNotes.Repositories** - шар доступу до даних;
- **PersonalProjectNotes.Services** - бізнес-логіка, перевірки прав доступу, обробка користувацьких дій;
- **PersonalProjectNotes.IntegrationTests** - тести сервісів і контролерів.

Серверна частина реалізована на платформі ASP.NET Core. Для роботи з даними використовується Entity Framework Core. Для автентифікації та керування користувачами застосовується ASP.NET Core Identity. Доступ до API захищається за допомогою JWT Bearer Authentication.

Основними сутностями системи є:

- користувач;
- дошка;
- список карток;
- картка задачі або нотатки;
- коментар;
- записи активності для дошок, списків і карток.

Система підтримує CRUD-операції для дошок, списків і карток, архівування елементів, пошук і фільтрацію, роботу з коментарями, керування співучасниками дошок, а також отримання історії активності.

Для документування та ручної перевірки API використовується Swagger. Для запуску в контейнеризованому середовищі передбачено Docker та docker-compose.
